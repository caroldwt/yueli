# 阅历 · 双离线手记

程序页面可以托管到 GitHub Pages；记录、感想、评分、合集和上传的图片都存储在当前设备的 IndexedDB 中。程序没有记录上传接口，也不自动跨设备同步。

## iPhone 安装
1. 用 Safari 打开发布后的 HTTPS 地址。
2. 点击分享 → 添加到主屏幕，名称“阅历”。如出现“作为网页 App 打开”，保持开启。
3. 从主屏幕图标重新打开，保持联网直到显示“离线就绪”。之后 Mac 可以关机，手机可以断网记录。
4. 请从桌面图标开始正式记录。Safari 标签页和安装后的 App 可能各有一份独立数据。

## Mac 使用
打开相同安装地址，等待“离线就绪”。可收藏该地址；支持的 Safari 可以“文件 → 添加到程序坞”。Mac 与手机各自独立保存数据。

## 手工同步与迁移
在有新内容的设备点击“导入 / 导出” → “生成完整 ZIP 备份” → “保存 / 分享备份”。iPhone 可保存到“文件”。把 ZIP 传到另一设备，选择“合并到现有记录”导入。图片和合集包括在内。

相同记录不重复；一边的后续修改可以更新到另一边。如果两边同时修改同一记录，会保留冲突副本。并发修改与删除时优先保留内容；合并也会同步没有冲突的删除操作。合集名称发生冲突时保留导入设备的本机名称。同步完可把合并后的 ZIP 再导回另一设备。

“替换全部记录”会用备份替换本机内容，并保留最近一次替换前的本机恢复备份。请通过“取回上次替换前备份”另存；后续替换会更新该恢复备份。

旧局域网版：先在旧版导出完整 ZIP，再在新版合并导入。新格式备份请在新版使用，不要导回旧服务器版。

## 数据保管
清理网站数据、卸载网页 App 或系统回收存储空间可能造成数据丢失。请定期把 ZIP 保存在程序以外的位置，换机前务必备份。离线程序无法承诺永久保存。

单张图片支持 JPG / PNG / WebP，最多 8 MB；完整 ZIP 备份最多 128 MB。图片较多时请关注备份大小和设备可用空间。

## 发布文件
仅上传 site/ 内的程序文件到独立 GitHub 仓库，并启用 Pages；不要上传旧版本的 data/ 或任何个人备份 ZIP。根路径和项目子路径均使用相对资源路径。HTTPS 是手机安装离线功能的必要条件，局域网 HTTP 地址不能替代。

本次已通过程序构建。受浏览器安全策略限制，本地浏览器自动验证未完成；需在 HTTPS 发布地址验证离线启动、图片记录及 ZIP 往返，iPhone 安装须在实际设备确认。
